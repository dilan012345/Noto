## Noto
Minimal notes app in a material 3 style

## Features
- Add notes
- Delete notes
- Share notes
- Dark mode / Light mode
- Save notes
- Export notes in the format:
      - Pdf
      - Docx
- Biometric app lock
- Hidden notes
- Locked notes (Requiring biometric authentication to access)
- Cloud Sync (Link to Onedrive)
- Autocorrect (using SerpAPI)
